STATEMENTS & SYSTEM COMMANDS

Core Engine
PRINT [expressions...]
Statement
PRINT [expr1] [; | ,] [expr2] ...
Outputs strings, numbers, variables, and expressions to the text terminal console. Separating items with a semicolon (;) prints values immediately adjacent with no extra space. Separating items with a comma (,) advances output to the next 14-column tab stop. If a statement ends with a semicolon or comma, the automatic trailing newline is suppressed.
Syntax FeatureDescription
; (Semicolon)Suppresses spaces and keeps the printing cursor directly adjacent.
, (Comma)Zones output in 14-column tabular increments.
TAB(n)Moves cursor forward to horizontal column n.
Empty PRINTPrints a blank line.
Example:
10 PRINT "PLAYER SCORE: "; 100; " PTS"
20 PRINT "ITEM", "QTY", "PRICE"
30 PRINT "SWORD", 1, 250
40 PRINT "LOADING";
50 FOR I = 1 TO 5: PRINT ".";: SLEEP 100: NEXT I
60 PRINT

INPUT ["Prompt";] variable
Statement
INPUT ["Prompt string";] <variable>
Suspends execution and prompts the user to enter data through the interactive terminal keyboard. If a prompt string is provided, it is displayed prior to the prompt indicator. Numeric variables will parse numbers (defaulting to 0 if invalid). String variables ending with $ accept arbitrary text input.
ParameterTypeDescription
"Prompt"String (optional)Message displayed before the input prompt.
variableIdentifierVariable name to receive input (e.g., NAME$, AGE).
Example:
10 INPUT "WHAT IS YOUR HERO'S NAME? "; HERO$
20 INPUT "ENTER YOUR AGE: "; AGE
30 PRINT "WELCOME "; HERO$; "! AGE "; AGE

LET var = expression
Statement
[LET] <variable> = <expression>
Assigns the evaluated result of an expression to a variable or array element. The keyword LET is optional; implicit assignment (e.g., X = 10) is fully supported.
Example:
10 LET SCORE = 0
20 LIVES = 3             ' Implicit LET
30 TITLE$ = "QUEST"
40 SCORE = SCORE + 100

IF condition THEN statement [ELSE statement]
Statement
IF <condition> THEN <statement | line_num> [ELSE <statement | line_num>]
Evaluates a boolean condition. If true (non-zero), executes the THEN clause. If false (zero) and an ELSE clause is provided, executes the ELSE clause. If a line number is specified directly after THEN or ELSE, it acts as a shorthand GOTO.
Example:
10 IF SCORE >= 1000 THEN PRINT "NEW HIGH SCORE!" ELSE PRINT "KEEP TRYING"
20 IF LIVES <= 0 THEN 100   ' Shorthand GOTO 100

FOR var = start TO finish [STEP step] ... NEXT [var]
Statement
FOR <var> = <start> TO <finish> [STEP <step>]
  ... statements ...
NEXT [<var>]
Iterates a numeric control variable from start through finish. If STEP is omitted, an increment of 1.0 is used. Negative steps count downwards. Nested FOR loops are fully supported.
Example:
10 FOR I = 10 TO 1 STEP -1
20   PRINT "COUNTDOWN: "; I
30 NEXT I
40 PRINT "BLAST OFF!"

WHILE condition ... WEND
Statement
WHILE <condition>
  ... statements ...
WEND
Executes a series of statements in a loop as long as the condition evaluates to true (non-zero). The condition is evaluated at the top of each iteration; if initially false, the loop body never runs.
Example:
10 COUNT = 1
20 WHILE COUNT <= 5
30   PRINT "POWER OF TWO: "; (2 ^ COUNT)
40   COUNT = COUNT + 1
50 WEND

GOSUB line_number ... RETURN
Statement
GOSUB <line_number>
...
RETURN
Pushes the current instruction return address onto the call stack and branches to the subroutine starting at line_number. When RETURN is reached, program flow resumes at the instruction immediately following the GOSUB.
Example:

30 PRINT "BACK IN MAIN"
40 END
100 PRINT "*** EXECUTING SUBROUTINE ***"
110 RETURN

DIM array_name(size)
Statement
DIM <identifier>(<size>)
Allocates memory for a 1-dimensional array capable of holding up to size elements. Elements are indexed from 0 to size. String arrays end with $ (e.g. NAMES$(10)) and initialize to empty strings. Numeric arrays initialize to 0.0.
Example:

30 SCORES(2) = 820

PSET (X, Y) [, color]
Graphics
PSET (X, Y) [, <color>]
Plots a single pixel at horizontal coordinate X (0 to 319) and vertical coordinate Y (0 to 199). If color is omitted, the active COLOR is used.
Example:
10 SCREEN 1
20 FOR X = 0 TO 319
30   Y = 100 + SIN(X * 0.05) * 40
40   PSET (X, Y), 10  ' Light green wave
50 NEXT X

Sprites

Checks bounding-box collision between sprite id1 and sprite id2. Returns 1 if the sprites intersect; returns 0 otherwise.

SOUND & SFX SYNTHESIZER

Real-Time DSP
SOUND freqHz, durationMs [, waveType]
Audio
SOUND <freqHz>, <durationMs> [, <waveType: 0..4>]
Synthesizes an audio tone at frequency freqHz (e.g. 20 Hz to 20,000 Hz) for durationMs milliseconds. The optional waveType parameter selects the synthesis oscillator waveform:
IDWaveformAcoustic Character
0Square Wave (Default)Punchy, classic chiptune 8-bit computer buzz.
1Triangle WaveWarm, mellow flute or deep bass tone.
2Sawtooth WaveBright, sharp synth brass with rich harmonics.
3Sine WavePure, smooth fundamental tone.
4White NoiseHiss, explosions, crashes, and percussion.
Example: Arpeggio:
10 SOUND 440, 150, 0  ' A4 Square wave
20 SOUND 554, 150, 0  ' C#5
30 SOUND 659, 250, 0  ' E5
